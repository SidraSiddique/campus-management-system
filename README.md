# Campus Management System

## Overview
A Python-based Campus Management System developed using Object-Oriented Programming (OOP) to manage student and teacher records and academic activities efficiently.

## Features
- Student Record Management
- Teacher Record Management
- Attendance Management
- Student Results and Grades
- Course and Academic Record Management

## Technologies Used
- Python
- Object-Oriented Programming (OOP)

## Purpose
This project aims to simplify campus administration, organize academic records, track student attendance, and manage results through an efficient, object-oriented approach.
